# AI Studio Enterprise v4.0 (Flutter Android APK)

نسخه کامل و سازمانی اپلیکیشن اندروید مدیریت و استفاده از API هوش مصنوعی‌های مختلف با بیلد خودکار GitHub Actions.

## قابلیت‌های کلیدی نسخه ۴.۰
1. **اتوماسیون و ابزارهای API:** دریافت خودکار لیست مدل‌ها (`/models`)، اتصال به Webhook و ابزارهای سفارشی (Function Calling)، و چرخش خودکار کلیدها (API Key Rotation) هنگام اتمام سهمیه.
2. **حافظه و پایگاه دانش (Local RAG):** آپلود فایل‌های PDF، جزوه و کد در «پایگاه دانش محلی» برای پاسخ‌گویی دقیق بر اساس منابع شخصی + حافظه بلندمدت سراسری (Global Memory).
3. **یکپارچه‌سازی با اندروید:** کاشی تنظیمات سریع (Quick Settings Tile)، ویجت صفحه اصلی (Voice & OCR)، پنجره شناور روی صفحه (Floating Bubble) و دریافت از منوی Share.
4. **تولید محتوای پیشرفته:** تولید فایل صوتی استودیویی MP3 (OpenAI TTS / ElevenLabs)، ویرایش تصویر (Image-to-Image)، و رندر گرافیکی نمودارهای Mermaid، فرمول‌های LaTeX و کدهای HTML/JS.
5. **مدیریت حرفه‌ای گفتگو:** ویرایش پیام‌های قبلی، تولید مجدد پاسخ (Regenerate)، خروجی PDF از کل گفتگو و مدیریت/پاک‌سازی حافظه کش رسانه‌ها.
